## 公開URL

https://1031pro.github.io/demos/

## リポジトリ

https://github.com/1031pro/demos

## 使い方

### 1. デモを追加する

```
Projects/Demos/案件名/
└── index.html（+ CSS/JS/画像など）
```

### 2. push する

```powershell
cd D:\OneDrive\Antigravity\Projects\Demos
git add -A; git commit -m "案件名 デモ追加"; git push
```

### 3. クライアントに共有

```
https://1031pro.github.io/demos/案件名/
```

pushから公開まで通常1〜2分。

## 注意事項

- **静的サイトのみ**（HTML/CSS/JS）。サーバーサイド処理は不可
- ファイルサイズ上限: 100MB/ファイル、リポジトリ全体1GB推奨
- **機密情報は入れない**（公開リポジトリ）
- 案件完了後、不要なデモはフォルダごと削除してOK
